# Get in touch

Amarantha is early and moving fast — the best way to reach the project
depends on what you've got:

- **Bug or feature request:** [open an issue](https://github.com/FrankFlitton/amarantha-md-editor/issues) on GitHub.
- **Thinking about a larger change:** open an issue first before sending a PR, so we can talk through the approach.
- **Something else — press, collaboration, just want to say hi:** [email Frank](mailto:fflitton@gmail.com) directly.
