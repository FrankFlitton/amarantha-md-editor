Yes. What you’re describing is a real category, usually called live-preview, WYSIWYM, or sometimes hybrid Markdown editing. And there are a few macOS apps that get surprisingly close to your desired interaction.

The important distinction is that you don’t want the Obsidian-ish behavior where clicking into a rendered paragraph suddenly expands **foo**, [link](...), etc. and causes layout reflow. You want the rendered document to remain structurally stable, with an escape hatch into raw Markdown when necessary.

I’d try these before building anything
Typora is probably the first one I’d install.

It’s explicitly designed around a single document surface rather than editor + preview panes. Markdown syntax is hidden/displayed intelligently, and it supports .md files directly, Mermaid, math, tables, code fences, images, HTML, and custom CSS. 

It’s also quite Mac-friendly: Apple Silicon native, document-based, and you can make it the default application for .md files. 

The catch is your custom blocks. MarkText is the open-source one I'd investigate.

It does genuine in-place WYSIWYG/live preview rather than a separate preview pane, supports Mermaid/math/etc., has a full source-code mode, and is free/open source.

What’s the story behind the name Amarantha?

Amarantha is an old feminine name derived from Greek ἀμάραντος (amárantos), meaning “unfading,” “undying,” or “that which does not wither.” It’s the same root behind amaranth, the flower/grain.







2
The symbolism comes from the amaranth flower’s reputation for retaining its color after being dried. Because of that, Greek and later Western literary traditions associated the amaranth with immortality, permanence, and enduring beauty. The name Amarantha is essentially a poetic feminine form: “the unfading one.”

It shows up especially in early-modern English literature. Poets used Amarantha as one of those pastoral/classical feminine names—alongside things like Cynthia, Celia, or Lucasta. Richard Lovelace, for example, wrote the 17th-century poem “To Amarantha, That She Would Dishevel Her Hair.”

And accidentally or otherwise, it’s a remarkably appropriate name for the thing we were just describing.

The whole architectural thesis is that the durable artifact is plain text:

Amarantha UI → Markdown/MDX → Git → another editor → an LLM → back to Amarantha

The visual editing environment can change, components can change, VS Code can disappear, the macOS app can be replaced—but the underlying document doesn't wither with the tool that created it.

So you get a pretty good little naming story:

Amarantha — an unfading editor for durable documents.
